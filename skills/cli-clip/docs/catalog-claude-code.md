# cli-clip 題材カタログ ─ Claude Code 基本操作「1操作＝1クリップ」（各1〜2分）

> 2026-09-08 起票（叩き台）。cc本編（`episode-briefs-claude-code.md`・`lecture-plan-claude-code.md`）が
> **「なぜ・どう使うか」を6〜8分で語る**のに対し、cli-clip は **「この操作は何をするか」を60〜120秒で見せる**逆引き短尺。
> 各回の正本＝ `clips/<id>/clip.json`。台本ルール・確定パラメータは `cc-production-runbook.md` に完全準拠。
> **制作環境は LLM 以外すべて無料・ローカル**（音声＝VOICEVOX のナレーター1人（config/voices.json の3声から選択）・キャラ掛け合いなし、字幕同期＝whisper.cpp）。「VOICEVOX:<話者名>」のクレジットを概要欄に必ず表記。
> **収録バージョンを毎回カードに明示**（UI/キーは使い捨て層＝変わる前提）。表示は実機キャプチャの清書＝捏造しない。

## 選定原則
1. **1クリップ＝1操作＝1つのWIN**。操作を2つ混ぜない（混ぜたくなったら2本にする）。
2. 順番はcc本編のラダーに沿う（止める→戻す→断る→頼む→取説→計画→検証→衛生→権限→拡張）。
3. cc本編に同じ操作の深掘りがある回は「詳しくは #N」で送客（重複を恐れない。短尺は入口）。
4. デモ題材は練習フォルダ（`make_practice_dir.sh`）で完結させ、実データ・実リポジトリを映さない。

## クリップの型（固定・60〜120秒）＝ タイトル → 説明スライド → デモで完結
```
t0  タイトルカード（無声 2.2s）: 「#NN」＋操作名だけ
x1  説明スライド（8〜12s）: できることを一文＋補足2つまで＋収録バージョン。最後に「では、実際にやってみましょう」
d1  状況（何を頼み、何が起きるか。10〜13s）              ← 画面は「頼む」→「動き出す」
d2  操作（キー可視化＋実録の反応。8〜10s）              ← 見せ場。実表示は原文ママ
d3  結果（何が残り、何が変わっていないか。8〜11s）→ そのまま終わる
（d4 意味づけ: デモで見せ切れないときだけ。判断基準は SKILL.md §4.3）
```
- **エンディング（今日の一歩・CTA）・エンドロール・BGM は付けない**（2026-09-09 キリ決定）。クレジットは概要欄。
- ナレーター1人（3声から選択）。キャラの掛け合い・アバターは使わない。語りは講師スタイルのですます調・開発用語を使わない（SKILL.md §4.1〜4.2）。
- 尺が2分を超えるなら操作を分割する（d を増やして粘らない）。
